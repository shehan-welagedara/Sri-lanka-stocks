# Enkira brand pack

Version 1.0, November 2026. Open **`guidelines.html`** in a browser for the full visual guide.

> Enkira is a working brand. The .com was available and a web search found no software company using the name, but trademark and company-name clearance in Sri Lanka are still pending. Use ™, not ®.

## Rules in one minute

- Keep clear space of half the mark's height around the logo. Smallest lockup 96 px or 25 mm wide.
- Do not recolour, stretch, rotate, outline or retype the logo.
- Write plainly: short sentences, real numbers, the owner's own words. Never overclaim.
- On client bills the client's logo leads; "Powered by Enkira" sits small at the foot.
- Copyright line: © 2026 Enkira Technologies. All rights reserved.
